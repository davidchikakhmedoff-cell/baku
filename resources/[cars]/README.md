# Новые модели транспорта

Эти ресурсы автоматически запускаются через `rp_car/meta.xml`. Названия общие для
автосалона, личных автомобилей и меню фракционных ключей; добавление названия
не создаёт предложение о продаже и не задаёт цену.

| Папка | ID GTA SA | Базовая модель | Название |
| --- | --- | --- | --- |
| aston_martin_db9 | 602 | Alpha, купе | ASTON MARTIN DB9 |
| bmw_f12 | 480 | Comet, спортивный кабриолет | BMW F12 |
| bmw_i8 | 451 | Turismo, спорткар | BMW I8 |
| ford_taurus | 550 | Sunrise, седан | FORD TAURUS |
| mercedes_sprinter | 413 | Pony, фургон | MERCEDES SPRINTER |
| skoda_octavia_universal | 458 | Solair, универсал | SKODA OCTAVIA UNIVERSAL |
| volkswagen_passat_cc | 445 | Admiral, седан | VOLKSWAGEN PASSAT CC |

Passat CC использует свободный после удаления `bmw_e39` ID 445. Удалённый ресурс
`bmw_e39` не следует сохранять в серверной папке ресурсов: он также заменял 445.
Полицейский Taurus остаётся на 597; гражданский Taurus использует отдельный 550.
ID остальных существующих заменёнок сохранены.

Служебные модели подключает `rp_fraction`: `cars/ambulance/ambulance.*` → 416
(AMBULANCE), `cars/news/newsvan.*` → 582 (NEWS CAR), `cars/copbike/copbike.*` → 523
(прежнее название HPV1000). Парковки, права доступа и количество транспорта не меняются.

Физический диаметр колёс новых моделей настроен отдельно для двух осей в
`rp_car/handling/base.lua` по размеру колёс загруженных DFF. Это не визуальное
масштабирование колёс. Настройки применяются после загрузки соответствующей модели,
а при остановке её ресурса восстанавливаются штатные значения. Доноры и настройка
подъёма Hummer 479 не изменены. Нужен клиент MTA с функциями
`getVehicleModelWheelSize` / `setVehicleModelWheelSize`.

После загрузки обновлённых папок выполните `refresh`, затем перезапустите `rp_car`
и `rp_fraction`. В игре проверьте высоту колёс и посадку водителя/пассажиров: без
графического клиента эти визуальные проверки не выполнялись.

Российский салон пока пустой: есть блип и маркер с уведомлением об отсутствии машин.
Лимузин (409) и специализированный фракционный транспорт не продаются.

`offer(id, model, price, maxSpeed, x, y, z, rotation, name)` задаёт отдельную
машину на площадке. Цены предварительные; для изменения цены поменяйте третий
аргумент. Название берётся из `VehicleModelNames` или последнего аргумента.
Не меняйте ID существующих салонов/предложений при редактировании цен.

`playerSpawn` задаёт точку взаимодействия/блипа, `purchasedVehicleSpawn` — выдачу
купленной машины, `cancelExitPosition` — выход после отмены покупки.
Для нового предложения нужна отдельная свободная позиция `x, y, z, rotation`.

В каталоге Америки также есть уже используемые сервером Hummer H2 (479) и
Ford Crown Victoria (546). Их заменённые DFF/TXD должны быть установлены на
сервере: без них MTA покажет стандартные модели этих ID.
Все 18 ресурсов моделей, доступных в текущем `[cars]` репозитория, перечислены
в `rp_car/meta.xml` как зависимости и запускаются автоматически.

# rp_fraction

Самостоятельный ресурс фракций для этого RP-проекта. Использует постоянный ID
аккаунта `rp_core`, его экономику, SQLite-соединение `auth.db`, динамический
`rp:id`, nametag, HUD, уведомления и блокировку интерфейсов. Новых аккаунтов,
игровых ID или отдельной базы денег не создаёт.
Поля сессии аккаунта защищены от клиентской подмены в `rp_core`;
фракция и ранг читаются из серверного состава, а не из клиентских element data.

## Установка

Если авторизация сообщает о неверном пароле после смены устройства, ядро
сохраняет соль хеша отдельно в `players.password_serial`, не подменяя её последним
serial входа. Старые записи мигрируют без смены паролей и игровых данных.
Уже повреждённую старой логикой привязку можно восстановить правильным паролем
с исходного устройства либо задать новый пароль в **серверной консоли**:
`authreset Name_Surname NEW_PASSWORD`. Из игры команда недоступна; она меняет
только пароль и его соль, сохраняя ID аккаунта, деньги, имущество и фракцию.

1. Остановите сервер и сохраните резервные копии `.db`.
2. Обновите **rp_core и rp_car** из этого же коммита: необходимы экспорты ID,
   адаптер гражданского скина/КПЗ и адаптер служебного транспорта с топливом.
3. Добавьте папку `rp_fraction` в resources. Не заменяйте существующие `.db`.
4. Запускайте `rp_core`, `rp_home`, `rp_car`, затем `rp_fraction`. Последний
   автоматически требует `rp_core` и `rp_car` через include в meta.xml.
5. Для автозапуска добавьте в mtaserver.conf:
   `<resource src="rp_fraction" startup="1" protected="0" />`.
6. Основатель (роль **Owner**, текущий последний уровень **10**) назначает лидера:
   `/setleader ID_ИГРОКА ID_ФРАКЦИИ`. Например, `/setleader 15 1` назначает игрока
   с ID 15 лидером Hospital. Используется **динамический ID над персонажем**;
   игрок должен быть онлайн и авторизован. Предыдущий лидер понижается до зама.
   `/setleader 15 0` снимает игрока с ID 15 с лидерства и полностью увольняет
   его из фракции, завершает смену, убирает служебное снаряжение и водительский
   доступ. Для обычного участника или заместителя снятие этой командой отклоняется.
   Нижестоящие администраторы команду использовать не могут.

Все команды с ID игрока используют существующий **динамический ID**. Фракционные
команды подключены к собственному чату `rp_core` через серверный адаптер;
неизвестные команды не передаются произвольным обработчикам MTA.

### Обновление уже работающего сервера

`restart rp_fraction` не перезагружает используемые им `rp_core` и `rp_car`.
Если MTA пишет `Included resource ... has changed but unable to reload`, новые
экспорты ещё не загружены. Обновите все три папки и полностью перезапустите
сервер либо выполните в его консоли по порядку:

```text
stop rp_fraction
stop rp_car
stop rp_home
restart rp_core
refresh
start rp_home
start rp_car
start rp_fraction
```

Ресурс проверяет загруженные экспорты до миграций и создания мира. Пока нужные
API отсутствуют, он ждёт и сообщает причину один раз, без повторного создания
52 машин. После загрузки зависимостей запуск продолжается автоматически.
Если сам адаптер регистрации отказывает, создание автопарка приостанавливается
до перезапуска `rp_car`, чтобы не повторять ошибочный вызов для каждой машины.

Последний ранг — лидер, предпоследний — заместитель. Лидер может управлять

приглашать и увольнять только нижестоящих. Никто не меняет себя. Лидерство
передаётся только административной командой. Уникальный индекс запрещает двух
лидеров одной фракции. Список `/members` включает офлайн-сотрудников и доступен
лидеру и заместителям. Управление составом выполняется только командами;
маркеров состава и кнопок приглашения/увольнения/ранга в окне списка нет.

Команды: `/invite ID`, `/uninvite ID`,
`/giverank ID ранг`, `/members`, `/f текст`.
`/coords` в чате выводит текущие x/y/z, поворот, interior и dimension. Команда
находится в `rp_core`, поэтому при этом обновлении обновите также этот ресурс.
Лидер и заместитель принимают игрока сразу через `/invite ID`, без подтверждения. Сервер проверяет
полномочия, расстояние, авторизацию и отсутствие другой фракции.

Полицейские команды нельзя применять к самому себе: штраф, розыск и его снятие,

запрещены в отношении любого сотрудника LSPD, включая находящихся вне смены.
Автоматический арест при гибели от полиции также не применяется к сотрудникам LSPD.
Офлайн срок заключения не уменьшается.
Вход и выход из штабов всех шести фракций доступны любому авторизованному игроку.
Доступ к ключам, оружию и началу смены по-прежнему требует членства и нужного ранга.
Русская мафия использует The Pig Pen (interior 2), появление: 1204.66, -13.54, 1000.92;
три её внедорожника — MERCEDES BENZ ML63 W164 (400), ресурс `mercedes_ml63_w164`.
При `/su` все полицейские получают светло-голубое сообщение:
«Внимание всем постам! Объявлен в розыск Ник. Уровень розыска - N. Причина: текст.» Розыск отображается шестью звёздами под HUD;
при нулевом розыске индикатор скрыт.

## Возрождение и самолечение в больнице

`rp_core` после смерти получает точку больницы через серверный экспорт
`getHospitalRespawnLocation`: `1479.2773, 1509.4697, 1183.5667`, interior 1,
dimension 20001. Распределение — по свободным точкам в пределах одного метра;
учитываются уже стоящие рядом игроки. Здоровье после появления — 20 HP, броня — 0.
Переход удерживает игрока до загрузки коллизии. При отсутствии ресурса используется
безопасная уличная точка; при действующем сроке КПЗ сохраняется приоритет тюрьмы.

В холле стоит круглый голубой маркер «Самолечение», цвет тюнинг-ателье
`79,195,247,115`. Если нет живых врачей на смене, меню предлагает лечение за $250
с кнопками «Лечиться» и «Отмена». Сервер повторно проверяет наличие врачей,
положение, здоровье и деньги при оплате. После успешной оплаты здоровье — 100 HP;
полное здоровье и повторные запросы не вызывают повторного списания.
Цена — `config.lua:selfHealPrice`; точки — `fleet_config.lua:respawnPoint/selfHealPoint`.

Вертолёт больницы находится на реальной крыше по координатам пользователя
`1163.55, -1329.41, 31.48`. Точка появления на крыше и обратный маркер стоят
рядом на той же высоте; искусственная площадка не создаётся.

## Работа, внешний вид и зарплата

Hospital, LSPD и News начинают/заканчивают смену у внутреннего маркера. Рабочие
команды и водительский доступ действуют только на смене. Мафиям смена не нужна.
News сохраняет собственный скин при начале/конце смены, возрождении и сохранении
аккаунта (`keepOwnSkin=true`); смена и зарплата продолжают работать. Блип News — 35.
Форма больницы определяется полом аккаунта и рангом:

| Ранги | Мужской аккаунт | Женский аккаунт |
| --- | --- | --- |
| 1–2 | 276 | 152 (`skins/hls/hls4`) |
| 3–4 | 275 | 145 (`skins/hls/hls3`) |
| 5, заместитель | 71 | 148, стандартная модель |
| 6, лидер | 70 | 91 (`skins/hls/hls1`) |

Форма применяется на смене; обычный скин сохраняется отдельно и восстанавливается
при завершении смены. Пол берётся из постоянной записи аккаунта на сервере.

Седан больницы — Volkswagen Passat CC (445), с прежним медицинским цветом автопарка.
Искусственная площадка и подложка под вертолётом больницы отключены. Позиции
вертолёта, маркера на крыше и появления заданы в `fleet_config.lua`.
Переходы на крышу и обратно доступны всем авторизованным игрокам без смены и
членства; ключи и оружейная сохраняют фракционные ограничения.
Обычный скин и оружие сохраняются отдельно; форма/служебное вооружение не
становятся гражданским снаряжением при сохранении аккаунта. Смена заканчивается
при выходе, увольнении и остановке ресурса; смерть сохраняет рабочий статус и форму после возрождения. Цвет ника передаётся через
`rp:nametagColor`, название в HUD — через `rp:faction`; реальное имя не меняется.

Почасовая зарплата учитывает только активное онлайн-время, для рабочих фракций —
только смену. После минуты бездействия прогресс приостанавливается. Остаток
миллисекунд хранится в SQLite и переживает reconnect. Уникальная запись выплаты
и SQLite-триггер начисляют деньги и уменьшают прогресс вместе, без повторной
зарплаты после рестарта. Ставки, интервал и AFK-порог — в `config.lua`.

## Механики

- `/heal ID`: медик на смене, живой пациент рядом, здоровье ниже 100. С пациента
  списывается $100 через экономику ядра, затем здоровье становится 100.
- Оружейные LSPD и мафий: доступ по фракции/рангу, лимиты патронов без ожидания
  между выдачами. Бронежилет доступен с первого ранга. Выбор оружия — выделением строк в списке: выдаётся только отмеченное одной заявкой.
  Патроны дополняются только до лимита, не складываются сверх
  него. При завершении работы/увольнении выдача убирается, возвращается исходный
  гражданский комплект. Изменение ранга завершает текущую смену/выдачу.
- `/ticket ID сумма причина`, `/tickets`, `/payticket НОМЕР`: штраф сохраняется,
  деньги списываются только после оплаты. SQLite-триггер предотвращает повторное
  списание и оплату без средств. Полицейский, оформивший штраф, получает 60%
  суммы только после оплаты, включая оплату, когда он офлайн. После выдачи
  `/ticket ID сумма причина` открывается компактное окно с суммой, причиной и
  кнопкой оплаты. Закрытие окна сохраняет штраф неоплаченным; `/tickets` открывает
  общий список. Выписать штраф самому себе нельзя. Дебет и выплата
  выполняются атомарно; старые оплаченные штрафы повторно не вознаграждаются.
- `/su ID уровень причина`: добавляет до шести звёзд. `/clearwanted ID` — с 9 ранга.
- `/cuff ID`: надевает наручники. Клиент меняет только кости рук и кистей,
  без анимации тела; положение рук настраивается в `config.lua:cuffPose`. `/uncuff ID`
  отдельно снимает их (повтор `/cuff` также поддерживается). Блокируются
  спринт/прыжок/оружие/атака/вход в автомобиль. При снятии клиент восстанавливает
  исходные состояния управления, полученные от сервера, включая F; заморозка
  администратора при этом сохраняется. Смерть/выход и уход
  полицейского очищают связанные наручники.
- `/arrest ID`: LSPD на смене, рядом с разыскиваемым перед КПЗ в интерьере.
  Центр `jailSpawn` и размеры `jailBooking` настраиваются в `fleet_config.lua`; арест с
  улицы или с верхнего этажа не разрешён. Причину вводить не нужно. Срок сохраняется в секундах, идёт только онлайн и не
  сбрасывается после выхода. Срок при любом аресте — 5 минут за звезду, максимум 30 минут.
  Появление заключённого: 264.28, 77.64, 1001.03, поворот 90°
  (точные координаты пользователя, без дополнительного смещения).
  Вокруг этой же точки действует зона команды радиусом 5 м, с допуском
  высоты 1.2 м, чтобы команда не работала с верхнего этажа. После срока или `/unarrest ID` игрок появляется
  перед главным входом LSPD (`outsideSpawn`). В измерении КПЗ действует зелёная
  зона: клиент отменяет входящий/исходящий урон и скрытные убийства.
  Адаптер возрождения ядра удерживает арестованного в КПЗ. Повторный арест не
  удваивает срок. Попытка покинуть измерение КПЗ возвращает заключённого в камеру.
- `/m текст`: сообщение над служебной машиной LSPD, следует за ней 10 секунд;
  ограничены длина, дистанция видимости и частота.
- `/add текст`: очередь News, одно ожидающее объявление на аккаунт. `/news` для
  сотрудников на смене: выбор, редактирование, публикация/отказ. Публикация
  атомарно меняет pending на published; триггер даёт редактору $150 один раз.
  В общем зелёном сообщении — автор, его динамический ID, редактор и текст.
  Ожидающие объявления уходящего автора удаляются. При рестарте ресурса
  объявления онлайн-авторов сохраняются, офлайн-авторов — удаляются.
- `/sms ID текст`: любое расстояние, $1, только авторизованные игроки, без
  отправки себе; плата берётся после всех проверок и перед доставкой.

## Транспорт и топливо

### Настройка автопарков

Все машины и их парковочные места находятся в **`fleet_config.lua`**.
Пользовательские парковки сохранены из загруженного файла. В конце этого же файла
находится `FractionLocationConfig`: `entrance`/`exit` — маркеры улицы и интерьера,
`inside`/`outsideSpawn` — появление после входа и выхода; `keysPoint`, `dutyPoint`,
`armory` — рабочие маркеры. `roof` и `garage` задают `inside`, `outside`, `arrival`,
`returnSpawn` — два маркера и две независимые точки появления. `interior` и
`dimension` относятся к интерьеру; внешние точки находятся в 0/0. LSPD имеет
переход в подземный гараж и обратно. Этот раздел переопределяет `config.lua`.
Не ставьте точки появления прямо на маркеры обратного перехода.

Разделы автопарков
`[1]`–`[6]` соответствуют ID фракций. Внутри — подписанные группы транспорта:

- `count` — количество машин группы; `0` отключает её.
- `model` — ID модели GTA SA; `rank` — минимальный ранг для получения ключей.
- `parking` — список мест: `x`, `y`, `z`, `rotation` задают положение и поворот.
- `slot` — постоянный уникальный номер машины внутри фракции. Сохраняйте его
  при переносе машины, чтобы сохранить её топливо. Для новой машины задайте новый
  свободный номер. Порядок групп и количество машин не меняют существующие номера.
- `helipad = true` — посадочная площадка у каждого активного места этой группы;
  при переносе вертолёта площадка переносится вместе с ним.
- `roofDeck = true` — дополнительная площадка с коллизией под вертолётом.
  По умолчанию включена для Hospital и LS News. Выход на крышу привязан к
  `roof.slot`; явные точки в `FractionLocationConfig` задают положение перехода независимо от вертолёта.

Например, чтобы оставить одну скорую, измените `count = 2` на `count = 1` в
первой группе Hospital. Чтобы добавить третью, добавьте в `parking` строку
с новым `slot` и координатами, затем задайте `count = 3`. Если количество больше
числа мест, ресурс использует доступные места и сообщает об этом в консоли.
Повторяющиеся номера и некорректные координаты пропускаются с диагностикой.
Учитывайте свободное пространство; расстояние между местами должно быть хотя
бы 3 метра. После изменения выполните **`restart rp_fraction`**.

### Работа транспорта

52 служебных транспортных средства зарегистрированы в отдельном серверном
адаптере `rp_car`, без записей в `personal_vehicles`. Клавиши 2/L/B/N и спидометр
используют существующий ресурс. Переключение замков, двигателя, фар и ручника
проверяется по серверному составу, рангу, смене и личному ключу. Любой
авторизованный игрок без наручников и срока КПЗ может сесть за руль открытой
машины. Если двигатель уже заведён, он продолжает работать и после посадки
игрока без ключей; заглушённый двигатель такой игрок запустить не может.
Закрытая машина не допускает посадку, отказ происходит без уведомления.
Проверка при посадке и периодическая проверка сохраняют запрет для заключённых,
игроков в наручниках и неавторизованных игроков, не высаживая водителя за отсутствие ключей.
N не показывает уведомлений при открытом чате, отсутствии цели или прав,
посадке/выходе и переключении замков. Звук замка и мигание фар сохранены.

Топливо подключено к FuelSystem: расход, пустой бак, заправка и возвраты остаются
серверными. Литры сохраняются в `fraction_vehicle_fuel`, включая восстановление
незавершённой заправки из существующего журнала. Уничтоженная машина возвращается
через настроенный интервал; занятое парковочное место не используется. Пассажиры
высаживаются у фракции и не задерживают возврат. При остановке/перезапуске сохраняются литры.

### Ключи

Вместо маркера состава в каждой фракции расположен маркер **«Ключи транспорта»**.
Он открывает dxDraw-список автомобилей/вертолётов с названием модели, номером
места, минимальным рангом, статусом и ником текущего держателя ключей. Статусы
обновляются у всех сотрудников с открытым окном. Государственные/News сотрудники
получают ключи на смене; мафиям смена не нужна.

У одного игрока может быть ключ только от одного транспортного средства;
у одного транспортного средства — только один держатель. Замки, двигатель,
фары, ручник и заправка доступны только держателю. У вертолётов замок и ручник
отключены, двигатель автоматически запускается при посадке допущенного пилота
при наличии топлива; ручные переключения N/B/2 не применяются. Пока ключи
никому не выданы, служебный транспорт защищён от потери HP и визуальных
повреждений; после выдачи ключей действует обычная модель повреждений. Права другого сотрудника или
более высокий ранг не заменяют ключ. Сервер проверяет маркер, фракцию, смену,
ранг и занятость транспорта при каждом запросе.

Ключи сдаются кнопкой у маркера и автоматически при выходе/смерти/завершении
смены, увольнении или потере доступа. Транспорт пересоздаётся на своей парковке
с сохранением топлива. Пассажиры сразу высаживаются у выхода своей фракции; их присутствие не задерживает
возврат. Если саму парковку занимает другая машина, ожидается освобождение места,
чтобы не создавать транспорт друг в друге. Уничтожение транспорта
освобождает ключи; срок восстановления остаётся заданным в конфиге. При рестарте
ресурса ключи сбрасываются, весь транспорт появляется свободным и закрытым.

## Мир и данные

Переходы фракций затемняют экран, временно фиксируют игрока и ждут клиентскую
коллизию пола. Экран открывается после подтверждения загрузки. Для гаража луч
проверяет только пол под заданной точкой, не выбирая улицу над ним. Если за 8
секунд пол не найден, игрок возвращается в исходный интерьер с уведомлением.
Координаты из пользовательского `fleet_config.lua` сохранены. В `rp_core` также
добавлено затемнение при смене интерьера/измерения и резком переносе позиции
другими ресурсами; обновлять нужно оба ресурса.

У всех шести штаб-квартир есть блипы на карте: Hospital — больница, LSPD —
полиция, остальные — точки фракционных цветов. На миникарте блипы появляются
в пределах 250 метров от входа, как у автосалонов и тюнинг-ателье. Общая дальность —
`FractionConfig.blipVisibleDistance`; для конкретной фракции её можно изменить
через `blip.visibleDistance`. Иконки и размеры также задаются в `blip`.
Входы используют жёлтые arrow-маркеры как дома. Надписи повторяют стиль домов:
`default-bold`, масштаб 1, голубой цвет `{0,190,255}`, обводка в восьми направлениях,
дальность 12 метров. Стиль един для всех фракций, настройки — `markerLabel`.
В Hospital, LSPD и News есть пары маркеров «На крышу» / «В интерьер», ведущие к
площадкам. Появление вынесено за зону обратного перехода; возврат дополнительно
обнаруживается сферой, независимо от высоты коллизии arrow-маркера. Окна ключей
и оружия используют чёрную таблицу, синее выделение и полосу прокрутки в стиле TAB.
Плавное появление окон отключено. Позиции вертолётов задаются в `fleet_config.lua`;
внутренние точки перехода и номер парковочного места — в `config.lua`, `roof`.
Для отключения перехода задайте `roof = false` в `FractionLocationConfig`.
Измерения
20001–20006, КПЗ 20100, без пересечения с домами/отелями. LSPD — стандартный
интерьер 6. News — Bike School, интерьер 3, точка появления `1494.85, 1306.47, 1093.29`, мафии — отдельные жилые/
деловые интерьеры. Hospital использует загруженную модель `laehospital1` из
`interior/`, интерьер 1, отдельное измерение 20001; вход — у All Saints General
Hospital в Market. Внутри доступны выход, ключи, смена и переход к вертолёту.
Модель создаётся на клиенте в отдельном динамическом слоте, исходная больница и
дороги на карте не заменяются. Пол и потолок проверяются по DFF и COL; используется
только коллизия `laehospital1`, выделенная из исходного архива `lae_5.col`.
Подробности настройки: [interior/README.md](interior/README.md).
Справочник интерьеров: https://wiki.multitheftauto.com/wiki/Interior_IDs.
Игроки с сохранённой позицией в старой больнице или на старой крыше News
перемещаются на актуальную внутреннюю точку при загрузке.

Миграции добавляют таблицы `fraction_members`, `fraction_state`, `fraction_tickets`,
`fraction_ads`, `fraction_rewards`, `fraction_vehicle_fuel` в **существующую**
базу rp_core. Старые таблицы не удаляются. Состав привязан к account_id; duty,
гражданский скин/оружие, зарплатный прогресс, розыск, КПЗ и
штрафы переживают перезапуск.

последовательность перезапуска проверена на MTA: после неё создаются все 52 машины.

Нужна ручная проверка с двумя игровыми клиентами: реальные коллизии/доступность
парковок и площадок на вашей карте, расположение маркеров в интерьерах,
комплекты/анимации, интерфейсы на разных разрешениях, реальная доставка чата/SMS,
сценарии смерти/КПЗ и посадки/пересадки, часовой прогресс зарплаты/AFK/reconnect,
взятие/сдача ключей двумя сотрудниками, управление чужой машиной, выход игрока,
выходы на крыши и коллизии новых площадок.
Проверка серверных элементов не заменяет
визуальную проверку в GTA SA. Координаты и мебель открыты в конфигурации/модуле
мира и могут требовать корректировки под ваши пользовательские карты.

Компактные окна смены, оружия и ключей используют оформление домов. Галочки и
подписи рангов скрыты, ограничения проверяет сервер с уведомлением. Кнопки стоят
в одном ряду; окно выдачи закрывается только после успешного ответа сервера.
Длинные списки прокручиваются колесом, нажатием и перетаскиванием правого ползунка.

Смена обозначается стандартным вращающимся pickup-футболкой GTA SA (1275),
ключи — вращающимся 3D-значком с ключом над скрытой зоной взаимодействия.
Окно смены показывает «Начать работу?» / «Завершить работу?», левая кнопка укорочена.
После спавна служебный транспорт через 1000 мс включается на ручник, если двигатель
ещё не запущен (кроме вертолётов); ранняя посадка водителя этому не мешает. Клавиша N работает из
машины для текущего ТС, снаружи — по центру экрана; собственные навесные объекты
не заслоняют цель. Сообщения управления выводятся через уведомления ядра.

Автоматическое КПЗ при гибели применяется только к разыскиваемому, которого
убил другой участник LSPD (в том числе служебным автомобилем). Ранг и смена
убийцы на этот факт не влияют. Гибель от гражданского, падения или самоубийства
не считается задержанием. Срок — 5 минут за звезду.

Розыск сохраняется в `fraction_state.wanted` по ID аккаунта при выдаче и снятии,
а не восстанавливается из временного состояния GTA. Возрождение, повторный вход
и перезапуск возвращают сохранённые звёзды; нативное обнуление при спавне не
перезаписывает БД. При помещении в КПЗ розыск обнуляется в памяти, GTA и SQLite.
Явная служебная `/clearwanted` остаётся доступной заместителю/лидеру.

`/arrest` направляется из чата прямо в обработчик фракции. Для проверки себя
используется собственный динамический ID, даже если обратный индекс ID ещё не
готов. Проверки LSPD, второго ранга, активной смены, розыска, близости игрока
и зоны КПЗ остаются обязательными. Каждый отказ и успешный арест выводятся
в видимый чат. Зона работает в публичном LSPD, измерении заключённых и
стандартном мире интерьера (dimension 0); дома и другие фракции не подходят.

## Женские формы LSPD и таймер КПЗ

Пол формы определяется сервером по `players.gender` постоянного аккаунта.
Гардероб LSPD использует следующую таблицу; формы нижних рангов также доступны:

| Минимальный ранг | Мужская форма | Женская форма |
| --- | --- | --- |
| 1 | 280 | 129 (`pw1`) |
| 2 | 281 | 130 (`pw2`) |
| 6 | 285 | 131 (`pw3`) |
| 9 | 283 | 150 (`pw4`) |
| 10 | 61 | 151 (`pw5`) |

В существующем маркере смены нажмите «Начать работу»: смена начнётся сразу,
а форма останется гражданской до выбора в гардеробе. Закрытие окна не завершает
смену. Во время работы тот же маркер предлагает «Сменить одежду» и «Завершить
работу». Выберите строку и нажмите «Надеть». Окно использует компоненты окна
ключей, поддерживает колесо мыши и перетаскивание правого ползунка.

Все настройки одежды находятся в `skins/config.lua`: `factions[2].groups`
задаёт минимальный ранг, пол, модели и названия. Для добавления мужской формы
284 с четвёртого ранга добавьте в `groups`:

```lua
{minRank=4, male={{model=284, name='Патрульная форма'}}, female={}},
```

На одном ранге можно указать несколько элементов `male`/`female`. Повторяющиеся
ID показываются один раз с минимальным рангом. Для другой фракции добавьте её
ID в `factions`; используется её существующий маркер смены. `models` задаёт
замены TXD/DFF; новые файлы также нужно зарегистрировать в `meta.xml`.
Загрузчик перенесён в `skins/models.lua`, `pw3` теперь заменяет ID 131.
Пользовательские мужские модели `p1`–`p4` заменяют ID 280, 281, 285, 283;
женские `pw1`–`pw5` — 129, 130, 131, 150, 151 соответственно.
Для каждой замены DFF и TXD должны принадлежать одной паре: например,
`p1.txd` и `p1.dff`, а не `pw1.dff`. Файлы новых загрузок сохранены.

Если через админ-панель видна стандартная модель, используйте `/checkskins`.
Команда показывает текущий ID и результат загрузки каждого пользовательского
скина, повторно пробует загрузить неудавшиеся замены и указывает точный этап
(`engineLoadTXD`, `engineImportTXD`, `engineLoadDFF`, `engineReplaceModel`)
или отсутствующий файл. Пол и ранг не влияют на замену ID через админ-панель:
замены действуют для всех персонажей с указанными выше девятью ID.
Для 298 замена больше не назначена; мужской ID 61 остаётся стандартным. Одна запись `<file>` в
`meta.xml` доставляет файл; для замены также нужен клиентский `skins/models.lua`
и таблица `skins/config.lua`, зарегистрированные в актуальном `meta.xml`.
Загрузчик повторяет сбой через 1,5 и 3 секунды, а также после завершения
скачивания соответствующего файла. Если ошибка сохраняется, уведомление
выводится в обычный чат без необходимости включать debugscript.


Сервер проверяет авторизацию, фракцию, активную смену, текущий ранг, пол,
модель из конфигурации и близость к маркеру. Одноразовый токен связывает запрос
с открытым окном. При изменении ранга гардероб предлагается сервером без
необходимости возвращаться к маркеру; недоступная форма сразу заменяется
минимальной разрешённой. Допустимая выбранная форма сохраняется при повышении.

Выбранная форма хранится отдельно в рабочей сессии; гражданский скин остаётся
в существующей БД. Смерть не завершает смену: выбранная форма возвращается при
возрождении. Завершение смены, увольнение, выход и остановка ресурса возвращают
гражданскую модель и очищают выбор. После reconnect нужно начать новую смену.

Реализация: `skins/config.lua`, `skins/server.lua`, `skins/client.lua`,
`skins/models.lua`; интеграция в `server/main.lua`, `server/members.lua`,
`server/world.lua`, `client/main.lua`, `config.lua` и `meta.xml`.
`tests/wardrobe_test.lua` проверяет десять комбинаций пола/ранга, реальные пути
смены/понижения/увольнения, подделку запросов, восстановление и конфигурацию.
Клиентские тесты проверяют выбор, статусы, прокрутку и размещение на четырёх
разрешениях. В игре вручную проверьте внешний вид загруженных моделей,
совпадение оформления с окном ключей и полный цикл смены двумя аккаунтами
разного пола, включая смерть, reconnect и перезапуск ресурса.

В КПЗ отображается оставшееся время MM:SS. Сервер присылает срок при аресте,
возрождении и раз в 5 секунд; клиент только отображает обратный отсчёт. После
освобождения таймер скрывается, при загрузке клиента запрашивается сохранённый
срок. После авторизации и при потере синхронизации клиент повторяет запрос.
Таймер остаётся видимым во время перехода между измерениями и располагается
выше блока даты/времени. Команда `/time` дополнительно обновляет таймер и пишет
оставшийся срок в чат в формате «КПЗ: осталось сидеть ММ:СС (мин:сек)».
Для обновления этой команды нужен также `rp_core/systems/hud/server.lua`.
Клиент не может изменить срок или самостоятельно освободить игрока.

Наручники больше не используют углы костей. Положение кистей рассчитывается
относительно таза с учётом длины плеча/предплечья каждой модели. Меняются только
матрицы рук, кистей и пальцев; анимация тела сохраняется. Параметры `cuffPose`
задают расстояние перед телом, высоту и зазор между кистями.

В меню ключей и уведомлениях показываются названия установленных моделей.


Исходные файлы выше сохранены как загружены. Для патрульных моделей
596/597/598 ресурс использует исправленные пары `cars/prepared/ID.dff` и `.txd`.

Привязка моделей и файлов, дистанция и интервал анимации задаются в
`cars/config.lua`. Замены действуют для всех автомобилей этих ID, в том числе
созданных администратором. Автопарк, ранги, парковки, ключи, топливо и управление
вертолётом используют прежнюю логику.

Короткое нажатие H (также поддерживается переназначенная клавиша сигнала)
циклически переключает: **мигалки без звука → мигалки с сиреной → выключено**.
Удержание дольше `hornHoldMs` (250 мс) включает обычный гудок и не переключает
режим; отпускание выключает гудок. Открытый чат/окно, пассажирское место и
выход из автомобиля не вызывают переключение. Остальные модели сохраняют
штатную обработку клавиши сигнала.

`cars/server.lua` проверяет авторизацию, водительское место, живого водителя,
отсутствие наручников/КПЗ и подходящую модель. Режим хранится сервером в
`fraction:sirenMode`; произвольная запись клиентом не меняет режим. Все
наблюдатели получают одно состояние: 1 включает материал мигалок без штатного
звука, 2 также включает штатную сирену, 0 отключает оба. Короткие нажатия
обрабатываются при отпускании; штатное мгновенное переключение GTA подавляется.
При взрыве режим сбрасывается; таймер удержания и принудительный гудок
очищаются при выходе, смерти и остановке ресурса.

Свет также включается при штатной активной сирене GTA, даже если серверный
режим ещё равен нулю. Это сохраняет работу освещения при внешнем переключении
или несовпадении версий обработчика клавиш. Невидимое закрытое окно ядра не
блокирует H; открытый чат и видимые окна продолжают блокировать ввод.
`/pdcontrols` показывает, загружен ли обработчик H, подходит ли водитель,
блокируется ли ввод окном, текущую модель, серверный режим и штатную сирену.
Если команда неизвестна, клиент не получил актуальный `cars/controls.lua`
через `meta.xml`. Ошибка создания шейдера выводится в обычный чат один раз.


В `cars/config.lua` яркость `sirenBrightness=4` (ранее 2), непрозрачность
`sirenOpacity=1.8` и порог удержания `hornHoldMs` можно менять без правки шейдера.
Для материалов мигалок подготовлены отдельные текстуры `rp_pd_els_*`.
Шейдер `cars/sirens.fx` читает номер лампы из текстуры-маски, независимо от
освещения и цвета материала GTA. Он применяется только к этим текстурам,
обычные фары, кузов и окна не попадают под эффект. При выключенных мигалках
маски не светятся; шейдер остаётся на загруженной машине и за пределами
дистанции анимации, чтобы служебные каналы маски не отображались как цвет.
`cars/patterns.lua` читает выбранный для модели набор из её JSON:
`emergency` для Explorer и `1.Emergency` для Taurus/Charger.
Поддерживаются наследование настроек через `reference` (например `strobe`) и
цветовые ключевые кадры `colors`: время в миллисекундах и цвет из `references.colors`,
с повторением по циклу рисунка мигания. Остальные настройки:
цвета/ссылки на цвета, начальное состояние, последовательность длительностей
в миллисекундах, постоянное свечение при пустом `pattern` и сглаживание `inertia`.
Параметр `models[ID].sirenState` позволяет выбрать другой имеющийся набор
именно этой модели: например `hazard`, `2.Emergency` или `3.park`.
Глобальный `sirenState` используется только при отсутствии настройки модели.
Размеры ламп задаёт геометрия DFF: поле `size` из внешнего формата не масштабирует
модель и не создаёт дополнительные короны. Это анимация реальных материалов
мигалок, без зависимости от внешнего ELS-ресурса.

В загруженном JSON два повторяющихся ключа `90` исправлены на **48** и **52**
по соответствующим компонентам DFF. Сам JSON сохранён рядом с моделью.
Анимация использует одну текстуру-палитру и один шейдер на загруженный рядом
Ford Explorer; обновление выполняется общим таймером, а не обработчиком каждого кадра.
При выключенной сирене лампы выключаются, при взрыве мигание останавливается.
Выгрузка/удаление машины и остановка ресурса освобождают графические элементы;
при остановке стандартные модели восстанавливаются.

Для установки обновите `rp_fraction` целиком, включая `meta.xml` и всю папку
`cars`, затем перезапустите ресурс. Автотест проверяет назначение ID, цвета,
ритм, нечётные последовательности, три режима, различение нажатия/удержания,
блокировку ввода в чате, серверные права, включение/выключение сирены, взрыв,
повторную загрузку и очистку. В игровом клиенте дополнительно проверьте
отображение обеих моделей, положение колёс/винтов, работу дверей и визуальное
мигание материалов при штатной сирене: графического MTA-клиента в среде проверки нет.


## Посадка задержанного в патрульный автомобиль

`/putcar ID` доступна LSPD со второго ранга на смене. Полицейский должен стоять
пешком в пределах 3 м от своего выданного автомобиля (ключи у него), задержанный
тоже должен стоять рядом с этой машиной и быть в наручниках. Проверяется серверная
запись наручников, авторизация, здоровье, интерьер/измерение и отсутствие срока КПЗ.
Самого себя или игрока, уже сидящего в машине, посадить нельзя.

Разрешены патрульные ID **596/597/598** (Explorer, Taurus, Charger). Транспорт
должен быть остановлен: скорость меньше 1 км/ч. Выбирается свободное заднее
сиденье 2, затем 3. Если оба заняты, переднее место не используется и никто не
высаживается. Наручники и ограничения управления после посадки сохраняются.
Параметры находятся в `config.lua:policeTransport` (`rank`, `radius`, `maxSpeed`, `models`).

Существующая `/eject ID` работает для водителя как раньше, а для полицейского
на смене также снаружи — около своего остановленного патрульного автомобиля,
если задержанный в наручниках находится сзади. Авторизация доступа выполняется
экспортом `getPoliceEjectVehicle`, сама высадка остаётся в `rp_car`. Задержанный
выходит на безопасную точку рядом с машиной, наручники не снимаются и управление
`enter_exit` не включается. Для остальных пассажиров сохранён прежний выход.

`/clearwanted ID` по-прежнему доступна заместителю/лидеру LSPD (9–10 ранг),
на смене рядом с игроком; для себя поддерживается собственный динамический ID.
Команда направляется из чата в обработчик напрямую и имеет отдельный cooldown,
поэтому только что выданный `/su` не блокирует снятие. Сначала сохраняется ноль
в SQLite, затем обновляются состояние фракции и звёзды GTA; ошибка БД не считается
успешным снятием розыска.

N при открытом меню автомобиля/чате молчит также в отдельном обработчике
`onClientKey`, который раньше оставался источником уведомления о закрытии окна.
Для установки этих исправлений обновите **rp_fraction и rp_car**, включая `meta.xml`.


### Подготовка моделей и устранение голубых участков фар

В Taurus/Charger исходные DFF содержат ссылки `siren128.png`,
`sirenlights128.png` и `sirenlight128`, не совпадающие с именами растров TXD.
При подготовке они сопоставляются с имеющимися `siren128` и `sirenlights128`.
Служебные цвета материалов `(номер,255,255)` заменяются нейтральным белым;
соответствующие поверхности получают маски с собственным именем и номером лампы.
Сохраняются интенсивность и прозрачность исходной текстуры. Это убирает голубые
метки с передних/задних ламп и позволяет независимо анимировать все модели.

Файлы `cars/prepared/596`, `597`, `598` генерируются инструментом:

```sh
python3 resources/rp_fraction/tools/prepare_car_lights.py
```

Для генерации/теста нужен Python с Pillow, для MTA — только готовые DFF/TXD и Lua.
Исходные файлы в `ford_explorer`, `ford_taurus`, `dodge_charger` не изменяются.
Вершины, треугольники, матрицы деталей, обычные материалы и исходные текстуры
сохраняются. Копии ламп добавляются в словарь TXD; JSON и управление H работают
как раньше. После замены исходной модели запустите инструмент повторно и
обновите подготовленную пару на сервере. JSON можно менять без повторной подготовки.

Проверка реальных бинарных файлов:

```sh
python3 resources/rp_fraction/tests/prepared_car_lights_test.py
```

Она сравнивает геометрию/материалы с оригиналами, проверяет ссылки на маски,
номера ламп в пикселях, прозрачность и число текстур. Для установки обязательно
обновите **всю папку `cars`, включая `prepared`, и `meta.xml`**, затем перезапустите
`rp_fraction`. Внешний вид фар и свет мигалок нужно дополнительно проверить
в игровом MTA-клиенте — графического клиента в среде проверки нет.


### Штаб-квартира Yakuza у склада

Вход и blip: **1767.88, −2020.14, 14.13**, поворот **180°**.
Появление после выхода из интерьера — перед входом: **1767.88, −2021.64, 14.13**,
поворот 180°. Все девять машин размещены рядом тремя рядами, с прежними моделями,
рангами и постоянными номерами мест. Точки входа/выхода находятся в
`fleet_config.lua:FractionLocationConfig[5]`, парковки — в `FractionFleetConfig[5]`.
Положение парковок относительно объектов склада нужно проверить в игре.


Если при обновлении сохранён старый стандартный `fleet_config.lua`, новый
`config.lua` переносит именно прежние стандартные точки Yakuza к складу,
до того как применяются настройки входа и создаётся автопарк. Настроенные
вручную другие координаты не заменяются. Это покрывает частичное обновление
пары файлов: старые значения 1081/-1696.8 больше не перезаписывают перенос.
После запуска в консоли сервера выводится фактически применённая конфигурация:

```text
[Fraction] Yakuza loaded: entrance=1767.88, -2020.14, 14.13; rotation=180; vehicles=9
```

Если этой строки нет после `restart rp_fraction`, сервер не загрузил новый
`server/main.lua` либо ресурс ещё ожидает зависимостей. Для проверки пришлите
вывод запуска ресурса. Полное обновление `rp_fraction` остаётся рекомендуемым.


Yakuza размещена у склада в **Los Santos**: координата **Y отрицательная**.
Ошибочная точка предыдущего переноса с Y=+2020.14 находилась в Las Venturas.
При загрузке старого конфига распознаётся и эта точка: вход, выход и стандартные
девять парковок переносятся в Los Santos. Новая парковка располагается перед
входом тремя рядами: Y=-2030.14, -2037.14, -2044.14, поворот 180°.


### Автомобиль 421 и двухцветная окраска Yakuza

Пять седанов Yakuza (места 1–5) используют модель **421 — LEXUX LS 400 XF10**.
Три внедорожника (места 6–8) используют **404 — TOYOTA SEQUOIA**. Позиции парковки,
постоянные номера, доступ со второго ранга и общее число машин сохранены.
Всем девяти машинам Yakuza задаются два RGB-цвета: тёмно-бордовый **35,5,12**
и чёрный **0,0,0** (`config.lua`, настройка `vehicleColor` для фракции 5).

Хэндлинг 421 хранится вместе с настройками автосалона в
`rp_car/handling/base.lua:VehicleHandling[421]`: `driveType="awd"`,
`suspensionLowerLimit=-0.13` (точное значение, указанное пользователем). Остальные параметры
421 остаются штатными. Фракционный адаптер теперь вызывает тот же
`applyConfiguredVehicleHandling`, что используется автосалоном/личным транспортом:
профили из этой таблицы применяются при каждой регистрации фракционной машины,
включая повторный спавн после сдачи ключей/взрыва. Отдельной таблицы хэндлинга
для фракций нет.

Модель ID 421 загружается ресурсом **lexus_ls400** из
`resources/[cars]/lexus_ls400`, модель ID 404 — ресурсом **toyota_sequoia**
из `resources/[cars]/toyota_sequoia`. Оба подключены через `<include>`
в `rp_fraction/meta.xml` и запускаются вместе с фракциями. Дублирования DFF/TXD внутри фракций нет.
Обновлённые пользователем позиции парковок и маркеров из GitHub сохранены.
Для обновления нужны **rp_car и rp_fraction**; перезапустите оба ресурса.


### Названия в меню ключей, N и оседание машин

Названия машин мафий берутся через `rp_car:getConfiguredVehicleName` из того же
`Dealerships[].vehicles[].customName`, что и автосалон. Правки/добавления в каталог
сразу используются в меню и сообщениях выдачи/сдачи ключей; отдельной таблицы
названий мафий нет. Для модели, которой в каталоге нет, используется штатное
название GTA. Именованные модели LSPD сохраняют свои названия из `cars/config.lua`.

Проверка N учитывает попадание луча в коллизию самой машины. Скрытый остаточный
флаг поля ввода после закрытия окна ключей не блокирует клавиши, но открытый чат
и видимые окна продолжают блокировать действия. Фракционный адаптер принимает
как список целей, так и конкретный автомобиль; пустой ID аккаунта не считается
совпадением с отсутствующим владельцем. Повторное событие замка в пределах
250 мс не переключает двери обратно. Серверные проверки ключей и расстояния
сохранены.

Машина на парковке получает флаг ручника через секунду, но физическая заморозка
ждёт **не менее секунды после загрузки машины клиентом** и ещё подтверждения
устойчивой высоты/скорости в течение **750 мс**. Одна кратковременная отметка
касания земли больше не замораживает подвеску в воздухе. При повторной загрузке
машины отсчёт начинается заново. Профиль 421 в `rp_car/handling/base.lua`
использует `suspensionLowerLimit=-0.13` и применяется через общий обработчик.

Для обновления нужны `rp_car` и `rp_fraction` целиком, включая оба `meta.xml`.
Загрузка фракций проверяет наличие нового экспорта названия, чтобы старый
запущенный `rp_car` не приводил к ошибкам при открытии ключей.


Названия 421/404 задаются в `rp_car/dealerships.lua:VehicleModelNames`:
**LEXUX LS 400 XF10** и **TOYOTA SEQUOIA** (точное написание пользователя).
Общий `getVehicleDisplayName` использует их в окнах автосалона, сохранённых
машинах и сообщениях; экспорт названий передаёт те же строки меню ключей.
Это справочник названий моделей, отдельные предложения продажи/цены не добавлены.
Пять Lexus, три Toyota и лимузин сохраняют прежние парковки, номера мест,
ранги и тёмно-бордовую/чёрную окраску. При установке переименованный ресурс
`new` заменён на `lexus_ls400`; обновите `meta.xml` и обе папки моделей.


### Toyota Sequoia: ID 404 и отдельный цвет

Ресурс `[cars]/toyota_sequoia/client.lua` заменяет **404** вместо 479.
В автопарке Yakuza места **6–8** также используют 404; парковки, ранги,
постоянные номера мест и остальные машины сохранены. Название
**TOYOTA SEQUOIA** в общем справочнике перенесено на 404.

Все автомобили Yakuza используют одинаковый тёмно-бордовый: основной RGB **35,5,12** (`#23050C`),

Обновите ресурс модели `toyota_sequoia`, `rp_car/dealerships.lua` и
`rp_fraction` (config, fleet_config, server/world.lua), затем перезапустите
модель и оба RP-ресурса. Отменённое изменение обязательных зависимостей
Lexus/Toyota не входит в это обновление.


### Посадка колёс Toyota 404, созданной под Huntley

Toyota остаётся на **404**, Huntley/BMW на **579** не изменяется.
В общем `rp_car/handling/base.lua:VehicleHandling[404]` заданы:

- `suspensionFromModel=579` — параметры подвески из **getOriginalHandling(579)**,
  а не из тюнинга уже заменённого BMW;
- `wheelSizeFromModel=579` — физические размеры передней/задней оси Huntley;
- `modelResource="toyota_sequoia"` — компенсация колёс активна при загрузке Toyota.

Сервер применяет исходные параметры подвески к личным/фракционным 404 через общий
обработчик. Двигатель, привод, масса и тормоза не копируются. Клиентский
`rp_car/handling/compatibility_client.lua` меняет только размеры колёс модели 404,
чтобы физическая опора и высота соответствовали заменёнке внедорожника.
Размеры 579 читаются и сохраняются как эталон, но не меняются. Шейдеры,
координаты парковки и геометрия исходной модели для этого исправления не правятся.

Настройка выполняется после загрузки ресурса модели, без цикла каждого кадра.
Неизменившиеся размеры повторно не применяются: это исключает постоянную
перезагрузку машин. При остановке Toyota/`rp_car` восстанавливаются прежние
размеры колёс 404. Для функций `getVehicleModelWheelSize/setVehicleModelWheelSize`
нужна актуальная клиентская версия MTA 1.6; при их отсутствии выводится одно
сообщение без ошибки Lua.
